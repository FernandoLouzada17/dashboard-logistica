# 📦 Dashboard Interativo de KPIs de Supply Chain

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://dashboard-logistica-djp9xkrs3wtarnssbv8ekv.streamlit.app/)

Este projeto é um painel interativo (Dashboard) desenvolvido em Python e SQL para monitorar indicadores críticos de logística, focado em identificar gargalos na distribuição e analisar custos de frete.

## 🎯 O Problema Resolvido
Empresas precisam monitorar a saúde de suas operações logísticas em tempo real. Entregas atrasadas geram insatisfação, e fretes mal calculados destroem a margem de lucro. 
Este dashboard consolida dados de pedidos e transportadoras para extrair insights acionáveis, como:
- Cálculo automatizado de **OTIF (On-Time In-Full)**.
- Identificação das transportadoras com maior volume de atrasos.
- Evolução financeira do custo de frete mensal.

## 🛠️ Tecnologias Utilizadas
- **Python:** Tratamento de dados e cálculos de regras de negócio (Pandas/NumPy).
- **SQLite:** Banco de dados relacional para estruturação e armazenamento de pedidos e transportadoras.
- **Streamlit:** Construção da interface do dashboard web.
- **Plotly:** Visualização de dados e gráficos interativos.
